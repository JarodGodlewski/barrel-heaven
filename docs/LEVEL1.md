# The Well — First sector (locked demo scope)

**Publisher:** Birddog Softworks
**Win:** survive **10:00** (Mercy jumps).
**Lose:** hull reaches 0.
**Boss:** ONE end-boss encounter, ~8:00–10:00 (Mercy jump). The old 5-ace
timeline is retired — mid-run tension comes from horde scaling + caches.

## Systems (port from js/ MVP)

| System | Space analog of VS | Notes |
|--------|-------------------|--------|
| XP motes | Gems | Drop from kills |
| Level-up | 3 cards, run pauses | 1 / 2 / 3 or tap |
| Hardpoints | Weapons (4 slots, max lv 5) | Start with Twin Laser |
| Systems | Passives (4 slots) | Coolant, Afterburner, Plating, Scoop, Gyro, Targeting |
| End-boss | Mercy jump encounter | Single escalating fight, 8:00–10:00 |
| Supply pods | Chests | Pod pickup **evolves** if a pair is ready, else bonus XP |
| Field caches | Chicken / vacuum / rosary | Cardinals: **patch**, **scoop**, **flare**, extra patch |

### Clock

| Time | Event |
|------|-------|
| 0:00 | Launch, Vicar / Hatch comms |
| ~8:00 | Mercy jump sequence begins — boss spawns |
| 10:00 | Boss defeated + timer elapsed -> win |
