# Pick up work

1. One task. Board `barrel-heaven`.
2. `studio/CONSTITUTION.md`
3. Role file `studio/roles/<role>.md`
4. `studio/products/barrel-heaven/profile.yaml`
5. Task body + `docs/WORLD.md` / `docs/PROGRESSION.md` if story or systems.
6. Code: `AGENTS.md`. Smoke if combat.
7. If blocked (extraction freeze, missing Chair): stop. Do not freestyle.
