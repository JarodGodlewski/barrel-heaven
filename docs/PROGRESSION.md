## The VS loop we actually want

Runs get *broken* because every toy multiplies the same short list of numbers — not because there are more toys.

```
kit base  ×  hangar powerups  ×  yolks  ×  in-run systems  =  this flight
                ↘ weapons / hop / bomb all read those numbers
```

If a hardpoint ignores a printed stat, it is a bug.

## Printed stats (show on kit select)

Same eight everywhere: select screen, pause, Pip's wrench panel.

| Print | VS analog | Feeds |
|-------|-----------|--------|
| **Punch** | Might | all damage |
| **Coolant** | Cooldown | fire interval (lower = hotter) |
| **Span** | Area | bolt size, nova, mines, magnet radius |
| **Knots** | MoveSpeed | cruise, boost, **hop hang + distance** |
| **Volley** | Amount | extra bolts / orbs / mines |
| **Hang** | Duration | orbit/nova lifetime, hop if we want a second lever |
| **Scoop** | Magnet | shard pull |
| **Plating** | Max Health | hull |

Kit select is a *stat sheet with a silhouette*, not a lore page.

### 2 — Secret job: Dry Mouth

Not a story dump. After Mercy jumps **once**, a fourth buoy can spawn off-cardinal. Scoop it → next launch offers **Dry Mouth**.

Dry Mouth: no Mercy, no win clock. 15 minutes, mean curtain, **Yolks** drop rare. Hatch: "She's gone. You're just greedy."

### 3 — Yolk (the golden egg)

Pip's word. +1 to **one printed stat on this kit**, infinite sink.

You do not start with Yolk access. Dry Mouth is the gate. That's the Cappella / inverse-farm beat without a spreadsheet screen on day one.

### 4 — Limit break + Pip's heresies

**Heresies** (Arcanas, later): radio pick at ~1:00 / 5:00 / 8:00. One weird rule (bolts steer, hop drops mines, nova on roll). Not a pause shop.

Field **salvage** that stays in the hangar = relics (radar pip, extra system slot, skip a card). One per sector, obvious pickup.

### 5 — Inverse curtain

A Well modifier: Gold Banner paint, faster unlock_scale. Unlocks after Dry Mouth + one Yolk spent. Same map, meaner math. Not a new biome.

## Routes (Star Fox) and the true string (Isaac)

VS is *one map, infinite numbers*. This game also needs **jobs on a map**, secrets that fork the next job, and a **final ending that is a recipe** — Star Fox 64 routes + Binding of Isaac completion marks.

The Well demo stays one job. The serious game is a tiny route sheet, not a campaign novel.

### Map (five nodes, that's the whole cart)

Same hole. Two lips. Five jobs. (Why: `docs/WORLD.md` — One hole.)

```
 The Well (wet lip)
     │
     ├─ just-survive ──────────────────────────► ending A (radio, hangar)
     ├─ stay / off-cardinal buoy ──────────────► Dry Mouth ──► ending C (Yolks)
     ├─ Kite hears you ────────────────────────► Gold Paint (wrong door, not true)
     └─ medal (+ hop-pack tears the curtain)
            │
            ▼
       Scrap Wake (Mercy’s peel)
            │
            └─ don’t chase her ──► Gold Paint (gold lip) ──► the Lock ──► ending B
```

| Job | Length | What it is in the world |
|-----|--------|-------------------------|
| **The Well** | 10:00 | Wet lip. Hold it. Mercy. Always first. |
| **Scrap Wake** | ~5:00 | The peel when she jumps. Debris. Medal only. |
| **Dry Mouth** | 15:00 | Wet lip, empty. Greedy. Yolks. Side path. |
| **Gold Paint** | ~6:00 | Twin mouth, Banner tickets. Kite. |
| **the Lock** | 10:00 | Inside the monkey. Heart was a door. Meanest weather. |

No sixth biome. Galleon is a **kit** you take *into* these jobs, not a planet.

Radio, one line each, then shut up: Pip “Wake’s open.” / Hatch “She’s gone. You’re just greedy.” / Kite “Wrong window, Rook.” / Hatch (Lock) says almost nothing.

### Secrets are verbs, not homework

Star Fox hidden routes = do a thing *in the flight*. Ours, all one-finger legal:

- **Medal:** never drop hull (or never spend Q). Lights Scrap Wake.
- **Hop-pack:** hop 8+ in one go. With medal, opens the hard fork.
- **Off-cardinal buoy:** Dry Mouth offer next launch (or encore same night).
- **Stay:** after Mercy jumps, don't quit — 30s of greedy flight can warp Dry Mouth *now*.
- **Kite hears you:** take a hit with 1 hull and live, or sit in a gold cache too long. Gold Paint.
- **No-bomb True:** the last job in the string refuses Q. That's the Andross-behind-the-fake beat.

Pip names the fork in one line ("Wake's open."). Hatch does not explain the map.

### Endings are a string

Isaac: the real ending is not "beat Mom." It is a **specific sequence**. Same here.

| Ending | String | What you get |
|--------|--------|----------------|
| **A — She's clear** | Well, survive | Hangar, crate kit. Radio win. **No real cine.** |
| **B — True jump** | Well (medal) → Scrap Wake → Gold Paint → **the Lock**, **one sitting** | **The movie.** Other side of the hole. Hatch quiet. Mercy already there. Galleon seed. |
| **C — Greedy** | Well → Dry Mouth (stay or buoy) | Yolk access. Not the true ending. A smirk, not a bow. |

Miss a medal, you fall back to A. That's Star Fox sending you to Katina instead of Venom.

**Payoff lives on B only.** Ending A is Hatch "Mercy's clear. Get out." and a cut to hangar. Spend the Bluth/Titan A.E. shots, the long camera, the one sincere Pip line, on the true string — and make that string the hardest thing in the cart. Replay is the price of the ending, not a lore dump on run one.

Marks on the kit door (Isaac grid, tiny): Well / Wake / Mouth / Paint / Lock. Three kits × five marks, not a wiki.

### One sitting vs unlocks

- **Unlock** (Isaac): doing a secret *once* puts the node on your map forever.
- **Execute** (Star Fox): ending B still wants the string **that night**. Unlocks are not a skip.

Length cap: True string ≈ 10 + 5 + 6 + 10. If that's fat, Scrap Wake and Gold Paint stay 4–5 min encore rules (no full Mercy clock).
